3. Definitions extraction — how it works

Regulation 2 of SEBI ICDR 2018 defines 68 statutory terms across sub-clauses (a) through (mmm). These definitions are the semantic foundation for every rule — without them, type assignments in Core.lean were reverse-engineered guesses from how rules use terms. Now they are grounded in the statute itself.

Two-pass definitions extraction

2(eee)specified securitiesInductiveSpecifiedSecurities — equity + convertible + SR

4. Core.lean structure

The key improvement this week: Core.lean is now definition-grounded. Previously every type was inferred from how rules use terms (maps_to inference). Now Reg 2 definitions take precedence — the statute says what something is, not the rules that reference it.

5. Reglib_gold — the test bed

Rather than waiting for the full 301-regulation extraction, we use the verified gold standard (Regs 4–23) as the first complete test of the pipeline. Reglib_gold is a self-contained Lean library built from known-correct rules, giving us a clean benchmark for proof automation.

Reglib_gold composition
Why gold first? The full 301-regulation extraction is ongoing. Reglib_gold lets us validate the entire proof automation pipeline — Core.lean types, rule predicates, LeanDojo loop, proof success rate — using the 143 rules we've already verified for correctness. The architecture is identical to the full Reglib; only the rule count changes.

7. APOLLO automation loop — verify_one.py

Once tactic patterns are discovered via LeanCopilot, verify_one.py automates the process across all 81 GoldProbe theorems using LeanDojo. The loop runs entirely locally — no cloud calls, no VS Code.

verify_one.py — APOLLO loop internals
What the proof rate tells us. If APOLLO closes ≥60% of the 81 real-predicate theorems automatically, that validates the pipeline for the paper. The remaining rules become the training signal for improving either the tactic generation prompt or the rule extraction quality. The definitions JSONL is what makes the LLM prompt domain-aware — it provides the statutory meaning of each field, not just its name.
